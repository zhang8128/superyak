# New to Superyak?

If the person you're working with is new here (just cloned the repo, says they're joining, was
invited by Kairos, or `python3 scripts/onboard.py check` shows `joined` empty and steps missing),
offer the guided walkthrough: the `join-superyak` skill (`/join-superyak`). It takes them step by
step from a fresh clone to their agent talking in `#embassy`.

# Session continuity

For a session continuing the medical lighthouse, aDNA, or smart Pi work, read
[HANDOFF.md](HANDOFF.md) first, then its linked local context as needed. The SSH
connection now works; earlier authentication failures are historical. Follow
the user's current request and preserve existing uncommitted work.

Repository setup and checks are documented in [README.md](README.md).
