# Session continuity

For a session continuing the medical lighthouse, aDNA, or smart Pi work, read
[HANDOFF.md](HANDOFF.md) first. It records the verified SSH connection and links
to the fuller local history. Treat dated observations as snapshots and follow
the user's current request.

uncommitted work when resuming.
