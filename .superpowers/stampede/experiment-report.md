# Experiment worker implementation

Owned files: `deploy/stampede/experiment.py`, `deploy/stampede/corpus/synthetic-engineering.json`, `engram/tests/test_stampede_experiment.py`.

`build_cells({})` returns 16 factorial cells and four one-agent, concurrency-one serial references. Explicit smaller population/concurrency arrays support offline mechanisms. An explicit positive `community_population` appends a separate individual+shared community. IDs and seed are deterministic; each condition has independent stores and audience.

`run_cell` appends the cell ID to both directory arguments. Live SQLite files are in `<local>/<id>/stores/`; result.json exists in both local and durable cell directories. `completed_turns` counts aggregate agent turns, including audited failed turns; `successful_turns`, `failed_turns`, and `agent_completed_turns` disambiguate this. `max_turns` is per agent. Terminal statuses are complete, complete_with_errors, interrupted, deadline, and call_budget. Resume retains IDs and skips durably completed agent turns/cells. Config/corpus identity mismatch fails closed.

Real Engram Storage holds a separate private audit history for each agent and a cell-local published store. Memory-off conditions retain audit records but never supply them as individual memory. Only an explicit JSON publication action invokes Engram `share`; the content is selected separately from private memory. `unshare` accepts only the caller's owned share IDs. Cross-cell audiences and unexposed/withheld source citations fail. Shared records retain source instance, original author, share ID, digest, and transitive parent-share ancestry, including when later recalled privately. Shared views are frozen at each round's start; withdrawals affect the next round. This avoids request-completion ordering changing exposure within a round.

The fictional cooling-valve evidence sequence partitions initial observations among agents, introduces a later gauge correction and firmware note, and contains a never-exposed source as a negative control. Every completed turn records the full actual task packet, source exposure, response, structured decision, and revision events. It is explicitly synthetic engineering evidence, not biomedical data. No model-supplied shell execution, remote access, private user memory, or model download occurs.

Requests use a bounded thread pool; all store writes occur on the owner thread. `cell_seconds` is cumulative across resumes, stop events are polled at most 100 ms apart while calls are in flight, and provider timeout is clipped to remaining runtime. The provider must honor its timeout: unfinished threads cannot mutate stores, but a broken custom provider that ignores timeouts cannot be killed by Python threads. SQLite checkpoints can take additional time after the inference deadline.

`max_calls_per_cell` defaults to 2048, `max_prompt_chars` to 32000 (including the system message). Whole memory entries are removed until prompts fit, preserving the actual supplied ancestry. Known input/output token values are summed; absent usage remains explicitly counted. Calls are reserved in a durable snapshot before dispatch so resume cannot exceed the call ceiling after an ambiguous crash. Thus `usage.requests` is a conservative count of reserved calls: interrupted reservations may or may not have reached the provider. `completed_requests` counts returned successes/errors and `attempts` distinguishes known not-sent, completed, error, and interrupted unknown outcomes. There is no claim of equal consumed tokens or equal longitudinal exposure between population settings.

One durable `flock` owner protects each cell. SQLite's backup API includes WAL content; complete generations contain every database, state.json, and a SHA256 manifest. CURRENT is switched only after the generation is complete and fsynced. Restore validates all hashes and copies into writable live stores. Unchanged immutable database snapshots may be hardlinked between generations; live files are never linked to snapshots. Two recent generations are retained; incomplete generations are ignored. Local work after the last complete generation is discarded on recovery. External inference whose outcome was never committed can be retried, but already completed turns are not.

Tests use real SQLite/Engram and deterministic model-boundary fixtures only. No hardware/deployment verification is claimed.

Community epochs use optional `session_seconds` to cap one invocation independently of the cumulative `cell_seconds` allowance. A deadline records `deadline_scope=session|cell`. This scheduling budget is excluded from stable identity, so a dedicated community or single-node interleaved epoch restores the same stores and agent histories. Cluster selects stable max_turns=1000 and max_calls_per_cell=1_000_000 for community from its first run; the experiment remains finite and reports its actual stopping reason. The additional test stops a community at its session ceiling and resumes under a longer session with no identity change.
